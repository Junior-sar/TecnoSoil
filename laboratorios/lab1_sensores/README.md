# Laboratorio 1: conexión y lectura de sensores con ESP32 y MicroPython

| Archivo | Función |
|---|---|
| `esp32/prueba_led.py` | Prueba inicial de la placa (LED RGB del ESP32-S3 en el GPIO 48) |
| `esp32/prueba_dht22.py` | Prueba rápida del DHT22 en el GPIO 4 |
| `esp32/main.py` | Plantilla universal de seis bloques, configurada para el DHT22 |
| `esp32/main_hcsr04.py` | La misma plantilla adaptada al HC-SR04 (solo bloques 1 a 4) |
| `esp32/registro_referencia.py` | 5 lecturas del DHT22 contra la temperatura del sensor 7 en 1 |
| `esp32/prueba_intervalo_dht22.py` | Pregunta 3: lecturas del DHT22 a 2, 1, 0,5 y 0,2 s |
| `resultados/` | Salidas reales de la consola de cada prueba |
| `Informe_Laboratorio_1.pdf` | Informe con registro de datos, preguntas y conclusiones |
